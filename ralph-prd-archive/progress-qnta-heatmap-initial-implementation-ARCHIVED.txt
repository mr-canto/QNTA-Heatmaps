## Codebase Patterns
- Supabase migrations use `IF NOT EXISTS` for idempotent table creation
- TypeScript types for database are in `src/types/database.types.ts` with convenience aliases like `Import`, `Property`, `OutcodeStat`
- RLS policies follow naming convention: `{table}_{action}_policy`
- All tables use UUID primary keys with `gen_random_uuid()` default
- Seed scripts in `scripts/` directory use CommonJS (.cjs) for Node.js compatibility
- Supabase service role key uses ES256 algorithm (not HS256) - get fresh keys via `npx supabase status -o json`
- Postcodes.io API supports bulk lookups (100 per batch) - terminated postcodes return 404 with termination info
- AppLayout wraps protected routes to provide consistent header - pages render inside `<main className="pt-[72px]">`
- Colour palette: teal (#0f5d5e), coral (#d16b55) per Design Specifications
- Use Recharts for charts: PieChart with innerRadius for donut, ResponsiveContainer for responsive sizing
- useDashboardStats hook provides aggregated stats (totalProperties, singleVisitCount, multiVisitCount, severeCount) from current import
- For count queries on properties table, use `select("id", { count: "exact", head: true })` pattern for efficiency
- Leaflet maps use react-leaflet: MapContainer (wrapper), TileLayer (tiles), ZoomControl for controls - import "leaflet/dist/leaflet.css"

Added comprehensive error handling with user-friendly messages and recovery options. Created Sonner toast notifications via ShadCN component for displaying errors with retry buttons. Added errorUtils library for converting technical errors to user-friendly messages. Created useQueryErrorHandler hook that automatically shows toast notifications for failed queries with optional retry functionality. Updated DashboardPage and HeatmapPage to use error handlers for all data queries. Enhanced LoginPage with inline form validation (email format, password length) and user-friendly auth error messages. Added toast notifications to ImportPage for geocoding errors and import success. Session expiry errors automatically redirect to login page.

### Learnings
- Sonner provides richColors prop for automatic success/error coloring
- useRef for toast IDs enables dismissing previous toasts to avoid duplicates
- Authentication errors detected by keywords: jwt, token, auth, session, expired
- Supabase auth errors like "Invalid login credentials" need friendly translation
- Form validation should clear field errors on input change for better UX
- Network errors detected by "failed to fetch" in error message
