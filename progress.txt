## Codebase Patterns
- Supabase migrations use `IF NOT EXISTS` for idempotent table creation
- TypeScript types for database are in `src/types/database.types.ts` with convenience aliases like `Import`, `Property`, `OutcodeStat`
- RLS policies follow naming convention: `{table}_{action}_policy`
- All tables use UUID primary keys with `gen_random_uuid()` default
- Seed scripts in `scripts/` directory use CommonJS (.cjs) for Node.js compatibility
- Supabase service role key uses ES256 algorithm (not HS256) - get fresh keys via `npx supabase status -o json`
- Postcodes.io API supports bulk lookups (100 per batch) - terminated postcodes return 404 with termination info
- AppLayout wraps protected routes to provide consistent header - pages render inside `<main className="pt-[72px]">`
- Colour palette: teal (#0f5d5e), coral (#d16b55) per Design Specifications
- Use Recharts for charts: PieChart with innerRadius for donut, ResponsiveContainer for responsive sizing
- useDashboardStats hook provides aggregated stats (totalProperties, singleVisitCount, multiVisitCount, severeCount) from current import
- For count queries on properties table, use `select("id", { count: "exact", head: true })` pattern for efficiency

## 2026-01-17 - US-003: Seed Initial Data Migration

### Implementation Summary
Created seed script to migrate property data from the XLSX file to Supabase. The script reads 15,902 rows, deduplicates by address to get 9,867 unique properties, validates/extracts UK postcodes, geocodes via Postcodes.io API, and stores data with calculated outcode statistics. One address without a postcode and one with a terminated postcode were correctly excluded, resulting in 9,866 properties across 18 outcode areas.

### Files Modified
- scripts/seed-initial-data.cjs (new)

### Learnings
- XLSX file has visits (15,902 rows) not unique properties - deduplication needed
- Address normalization: trim and collapse whitespace before comparing
- UK postcode regex handles variable spacing: `/([A-Z]{1,2}[0-9][0-9A-Z]?\s*[0-9][A-Z]{2})/i`
- Postcodes.io terminated postcodes (like SE15 2QX) return 404 but include termination info
- Batch inserts in 500-property chunks for performance
